# Excel 到货时间与收入月份工具

本仓库用于建设一个本地 Excel 处理工具：读取一个业务工作簿中的遗留量、可选当月订货、要货明细和国家运输周期等 Sheet，生成基表、RPD/CPD 跨月变化清单及异常清单。

## 当前状态

当前仓库处于**需求与设计基线阶段**。早期 POC 代码已经删除，尚无可运行正式版本。

后续实现必须遵循当前需求和系统设计，不得恢复旧 POC 的输入模型、字段命名、运输周期规则或统计逻辑。

## 权威文档

- `docs/requirements-baseline.md`：总体业务需求、处理边界和异常原则
- `docs/source-schema.md`：源 Sheet、源字段、匹配、类型和重复数据契约
- `docs/output-schema.md`：最终基表 29 列规则
- `docs/comparison-output.md`：RPD/CPD 跨月变化清单
- `docs/system-design.md`：后续实施架构、模块边界、数据模型和开发阶段
- `docs/decisions/`：已确认的单项业务决策
- `docs/reviews/`：需求与资料一致性审查结果

发生冲突时，先修订需求文档，再修改设计、代码和测试。不得由代码反向定义业务规则。

## 当前核心设计

- Python 3.11+、Windows 本地运行
- openpyxl 仅作为 Excel 输入输出适配器
- 源字段名、稳定内部字段 ID、输出显示名称三层解耦
- 领域规则不依赖 Sheet 名、列字母、VLOOKUP 或 Excel 样式
- 所有可恢复业务异常写入异常清单，其他合同继续处理
- 真实业务数据、历史结果和本地配置不提交公共仓库

## 数据安全

本仓库只能提交代码、文档、默认配置和虚构测试数据。禁止提交真实合同号、金额、客户、项目、业务工作簿、运行结果或历史快照。
