# Excel 收入统计工具

## Windows 使用方式（推荐）

1. [直接下载 ExcelRevenueTool-v0.11.0.exe](https://github.com/olu37776-bit/excel-arrival-tool/releases/download/v0.11.0/ExcelRevenueTool-v0.11.0.exe)。
2. 双击 `ExcelRevenueTool-v0.11.0.exe`。不需要安装 Python，也不需要运行 BAT 或打开终端。
3. 在窗口中选择三个必选源文件，并按需选择当月订货文件：
   - 遗留量 Excel
   - 当月订货 Excel（可选；没有时留空）
   - 要货明细 Excel
   - 国家运输周期 Excel
4. 无需选择汇总月份，程序自动识别数据中实际出现的收入年月。
5. 选择结果保存位置，点击“开始生成”。生成期间窗口保持响应；完成后可直接“打开结果”或“打开所在文件夹”。

第一次运行时，“上一次成功结果”留空。以后需要跨期比较或继承人工填写字段时，选择上一次成功生成的结果文件。

v0.11.0 兼容缺少新增系统列的旧版上期结果：按本期源数据补算收入预测和最终字段，并保留可继承的人工调整。四个最终字段同时保存公式与初始计算值，生成后即可读取；旧文件本身不会被修改，请用新版重新生成。

如果 Windows SmartScreen 提示未识别应用，这是因为程序尚未购买代码签名证书；可点击“更多信息”后选择“仍要运行”。

## 地区收入汇总

固定生成“RPD地区收入汇总”和“CPD地区收入汇总”两张表。第一列为地区部，所有实际出现的最终收入年月按时间向右排列，跨年不混淆。每个月依次显示订未发、发未收、交未验、其他、小计，最后一行为小计；不再生成前期累计。

- 基表与汇总不加工作表保护，可以筛选；基表可以编辑、排序及自行创建透视表。
- 汇总保留原生透视表的下拉筛选。双击**金额单元格**查看对应月份、地区和类别的明细，包括每月小计和末行小计。
- 在基表黄色人工字段输入后，四个最终字段通过公式更新。随后点“数据 → 全部刷新”更新汇总；人工月份改到新的年月后，刷新会增加相应月份。
- 请填写“调整收入分段类别”“调整月份（按RPD）”“调整月份（按CPD）”“调整金额”，不要覆盖相邻的最终公式列。明确填写金额0也有效；清空人工字段恢复自动结果。
- 如果最终字段没有更新，先检查 Excel“公式 → 计算选项 → 自动”，并确认最终单元格仍含公式。Excel计算模式可能受先打开的工作簿影响。用户实机未更新的问题仍在 #45 跟踪，需要实际文件确认原因。
- 汇总金额由透视表计算；需要改金额时请改基表再刷新。隐藏辅助源包含分类和小计副本，请使用基表自行透视。
- 无有效收入年月时，两张汇总显示提示，不虚构月份。

## Python 方式（备用）

电脑已安装 Python 3.10 或更高版本时，可以解压[源码](https://github.com/olu37776-bit/excel-arrival-tool/archive/refs/heads/main.zip)，然后在工具目录执行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m revenue_tool.gui --config .\config\default.json
```

图形窗口中的四个源文件可以位于任意文件夹，不需要放进工具目录。

## 常见问题

- 双击 EXE 后首次显示较慢：单文件程序需要先解压运行组件，请等待几秒。
- 提示“工作簿不存在”：重新选择文件，并确认文件没有被移动或重命名。
- 输出路径必须包含文件名和 `.xlsx` 后缀。
- 输出文件不能覆盖源文件或作为输入的上一次结果。
- Excel 文件正在打开时可能无法覆盖原结果，请先关闭该文件。
- 公司安全策略直接拦截 EXE：需要由公司 IT 放行，或改用上面的 Python 方式。
