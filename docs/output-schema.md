## 2. 业务粒度

基表正常业务行粒度：

```text
合同号 + 履行供应中心
```

合同全集先由三个独立业务源表的合同号并集去重，再由要货明细展开履行供应中心。

遗留量、当月新订货以及合同属性按合同号取得；同一合同有多个履行供应中心时复制到各行，不拆分、不分摊。

合同进入全集但要货明细中没有匹配合同号时，不生成正常业务行，原因进入异常清单。

## 3. 金额输出

### OS-AMOUNT-001 `[CONFIRMED]`

`遗留量`和`当月新订货`必须保持数值列，便于后续透视和汇总：

- 源单元格为空、空字符串或仅含空白字符 → `0`；
- 源值为`(空白)`或`#VALUE!` → `0`；
- 合同在对应来源中无匹配记录 → `0`；
- 合法金额 → 实际金额；
- 其他非法非空金额 → 异常清单记录原因，基表输出`0`。

不得输出空字符串或文本`0`。

## 4. 同合同多行与组内文本

遗留量、当月订货和合同级属性：

- 完全重复行先去重；
- 同合同仍有多行时按源表顺序取第一条；
- 当前不求和、不取最大、不分摊；
- 合同级冲突按需求基线的异常规则处理。

同一`合同号 + 履行供应中心`下，普通文本字段存在多个不同非空值时，不报文本冲突异常；需要单值时取去重后第一条有效值。

## 5. 字段来源优先级

- BG：遗留量 `行销产品维BG中文名称` → 当月订货同名字段 → 要货明细 `BG_CN`；
- 地区部：遗留量 `地区部中文名称` → 要货明细 `地区部`；
- 国家：遗留量 `国家中文名称` → 要货明细 `国家中文名称`；
- 客户群：遗留量 `客户群中文名称` → 要货明细 `签约客户群`；
- 项目名称：遗留量 `交付项目中文名称` → 要货明细同名字段；
- 贸易术语：要货明细；
- 履行供应中心：要货明细 `供应中心简称`。

优先来源为空时继续下一来源。

## 7. 标记字段

### 7.1 多个供应中心发货

```text
同合同不同有效履行供应中心数 > 1 → Y
否则 → N
```

### 7.2 是否解锁备货

读取同合同+履行供应中心下去重后的真实记录中的`备货总控标识`，按原出现顺序用`|`拼接。

示例：`Y|Y|N`。

空白字符、`(空白)`、`#VALUE!`按空值处理。展示方式后续可修改，不改变原始多值保留策略。

### 7.3 分批发货

完全重复明细先去重，再判断：

```text
同合同+履行供应中心真实记录数 > 1 → Y
否则 → N
```

### 7.4 多次要货

```text
不同有效RPD日期数 > 1 → Y
否则 → N
```

### 7.5 分批供应

```text
不同有效CPD日期数 > 1 → Y
否则 → N
```

## 8. 海运周期

贸易术语规范化后：

```text
FCA / FOB / EXW → 5
```

其他贸易术语：

```text
国家 + 履行供应中心
→ 国家运输周期表
→ 运输周期
```

找不到时海运周期为空并写异常清单。运输周期单元格显示格式为`#,##0`、底层为非整数浮点时，按Excel零位小数显示结果四舍五入取整，不直接截断。

## 9. 日期规范化与聚合

同一合同+履行供应中心：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- 最晚ASD = MAX(`ASD日期`)
- 最晚RPD = MAX(`RPD日期`)
- CPD = MAX(`CPD日期`)

以下值按空日期处理并安静排除，不写异常：

- 空单元格、空字符串、空白字符；
- `(空白)`；
- `#VALUE!`。

其他非法非空日期才进入异常清单。

## 10. 货未发完

```text
最晚ASD、最晚RPD均有效且最晚RPD > 最晚ASD → Y
最晚ASD、最晚RPD均有效且最晚RPD <= 最晚ASD → N
任一值无有效日期 → 留空
```

因正常空值或`#VALUE!`无法判断时不写异常。

## 11. 到货日期

到货日期必须先判断`货未发完`。

### 11.1 按RPD

```text
如果 货未发完 = Y：
    最晚RPD和海运周期均有效 → 最晚RPD + 海运周期
    否则 → 留空

如果 货未发完 != Y：
    ATA有效 → ATA
    否则ASD有效 → ASD
    否则 → 留空
```

### 11.2 按CPD

```text
如果 货未发完 = Y：
    CPD和海运周期均有效 → CPD + 海运周期
    否则 → 留空

如果 货未发完 != Y：
    ATA有效 → ATA
    否则ASD有效 → ASD
    否则 → 留空
```

规则边界：

- `货未发完=Y`时不使用已有ATA/ASD覆盖未完成批次的预计到货日期；
- `货未发完!=Y`时不回退到RPD/CPD加周期；
- ATA、ASD、RPD/CPD均无有效值时直接留空，不写缺日期异常；
- 选择的分支需要海运周期但海运周期不可用时，到货日期留空，同时保留运输周期异常。

## 12. 收入年月

- 收入年月（按RPD） = 对应到货日期的年月；
- 收入年月（按CPD） = 对应到货日期的年月；
- 到货日期为空时收入年月为空。

## 13. 收入分段类别

每次运行重新计算：

```text
1. 多次要货 = Y
   → 需判断

2. 多次要货 != Y，且ATA或ASD任一有效
   → 发未收

3. 多次要货 != Y，ATA/ASD均无有效值，且RPD或CPD任一有效
   3.1 遗留量 = 0 且 当月新订货 = 0
       → 未录入订货
   3.2 遗留量、当月新订货任一不为0
       → 订未发

4. 多次要货 != Y，ATA/ASD/RPD/CPD均无有效值
   → 不要货
```

收入分段使用金额规范化后的数值0，不再区分“空金额”和“0金额”。

## 14. 三个人工字段

只有以下三列人工维护：

- 是否手工调整收入月份
- 手工调整收入月份
- 调整备注

首次运行或新业务行为空；后续按`合同号 + 履行供应中心`继承上一期值。

## 15. 异常与空值

所有可恢复异常写入`异常清单`并继续处理。

不写异常的情况：

- 空白字符、空字符串、`(空白)`、`#VALUE!`；
- 同合同+履行供应中心内普通文本字段存在多个不同非空值；
- 因所有相关日期为空而使到货日期留空；
- 遗留量或当月新订货为空并规范化为0。

必须记录的相关异常包括：

- 合同进入全集但要货明细中没有该合同；
- 合同匹配要货明细但不能形成履行供应中心业务键；
- 同一要货明细记录中备货总控标识和发货总控标识均有效但值不同；
- 运输周期组合缺失或非法；
- 字段缺失、字段歧义及其他非法非空值。
