## 2. 业务粒度

基表正常业务行粒度：

```text
合同号 + 履行供应中心
```

合同全集先由三张业务表合同号并集去重，再由要货明细展开履行供应中心。

遗留量、当月新订货以及合同属性按合同号取得；同一合同有多个履行供应中心时复制到各行，不拆分、不分摊。

## 3. 同合同多行

遗留量、当月订货和合同级属性：

- 完全重复行先去重；
- 同合同仍有多行时按源表顺序取第一条；
- 后续出现不同非空值，写异常清单；
- 字段为空允许；
- 不阻塞运行。

## 4. 字段来源优先级

- BG：遗留量 `行销产品维BG中文名称` → 当月订货同名字段（若有）→ 要货明细 `BG_CN`；
- 地区部：遗留量 `地区部中文名称` → 要货明细 `地区部`；
- 国家：遗留量 `国家中文名称` → 要货明细 `国家中文名称`；
- 客户群：遗留量 `客户群中文名称` → 要货明细 `签约客户群`；
- 项目名称：遗留量 `交付项目中文名称` → 要货明细同名字段；
- 贸易术语：要货明细；
- 履行供应中心：要货明细 `供应中心简称`。

优先来源为空时继续下一来源。

## 5. 结转类型

遗留量表 `国家中文名称` 属于以下任一国家时：

- 阿拉伯联合酋长国
- 巴基斯坦
- 巴西
- 菲律宾
- 马来西亚
- 沙特阿拉伯
- 印度尼西亚

输出：`交付类`。其余留空。

## 6. 标记字段

### 多个供应中心发货

```text
同合同不同有效履行供应中心数 > 1 → Y
否则 → N
```

### 是否解锁备货

读取同合同+履行供应中心下去重后的真实记录中的 `备货总控标识`，按原出现顺序拼接，当前分隔符定为 `|`。

示例：`Y|Y|N`。

后续如确认只保留单值，可单独修改输出适配，不改变源记录保留策略。

### 分批发货

完全重复明细先去重，再判断：

```text
同合同+履行供应中心真实记录数 > 1 → Y
否则 → N
```

### 多次要货

```text
不同有效 RPD 日期数 > 1 → Y
否则 → N
```

### 分批供应

```text
不同有效 CPD 日期数 > 1 → Y
否则 → N
```

## 7. 海运周期

贸易术语规范化后：

```text
FCA / FOB / EXW → 5
```

其他贸易术语：

```text
国家 + 履行供应中心
→ 国家运输周期 Sheet
→ 运输周期
```

找不到时海运周期为空并写异常清单。

## 8. 日期聚合

同一合同+履行供应中心：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- CPD = MAX(`CPD日期`)

空值允许；非法非空日期写异常并排除。

## 9. 到货日期

### 按 RPD

```text
有ATA → ATA
否则有ASD → ASD
否则RPD和海运周期均有效 → RPD + 海运周期
否则 → 留空并记录原因
```

### 按 CPD

```text
有ATA → ATA
否则有ASD → ASD
否则CPD和海运周期均有效 → CPD + 海运周期
否则 → 留空并记录原因
```

决定最终到货日期的必要输入不能为空；若缺失，只影响该字段/该行，不阻塞整批。

## 10. 收入年月

- 收入年月（按RPD） = 对应到货日期的年月；
- 收入年月（按CPD） = 对应到货日期的年月；
- 到货日期为空时收入年月为空。

## 11. 收入分段类别

```text
1. 多次要货 = Y → 需判断
2. 否则 ATA 或 ASD 任一有效 → 发未收
3. 否则 RPD 或 CPD 任一有效 → 订未发
4. 否则 → 不要货
```

每次运行重新计算。

## 12. 三个人工字段

只有以下三列人工维护：

- 是否手工调整收入月份
- 手工调整收入月份
- 调整备注

首次运行或新业务行为空；后续按 `合同号 + 履行供应中心` 继承上一期值。

## 13. 异常与空值

一般业务字段允许为空。所有可恢复异常写入 `异常清单` 并继续处理。

当异常导致某个计算字段无法得到可靠结果时，该字段留空并记录原因，不猜测、不填默认值。
