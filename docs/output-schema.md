## 2. 业务粒度

基表正常业务行粒度：

```text
合同号 + 履行供应中心
```

合同全集由遗留量、当月订货、要货明细三个独立源表的合同号并集去重，再由要货明细展开履行供应中心。

遗留量、当月新订货和合同属性按合同号取得；同一合同多个履行供应中心时复制到各行，不拆分、不分摊。

若合同进入全集但要货明细完全找不到该合同号，不生成正常行，进入异常清单。

## 3. 金额字段输出

### OS-AMOUNT-001 `[CONFIRMED]`

`遗留量`和`当月新订货`必须始终输出数值：

- 正常数值按原值输出；
- 空单元格、纯空白、`(空白)`、`#VALUE!`及等价VALUE标记输出 `0`；
- 当月订货按合同号无匹配时输出 `0`；
- 其他非法非空金额记录异常，并输出 `0`。

不得输出空字符串或空单元格，以免影响后续汇总和收入分段判断。

## 4. 同合同多行

遗留量、当月订货及合同级字段：

- 完全重复先去重；
- 去重后仍多行，按原表顺序取第一条；
- 当前不求和、不取最大、不分摊；
- 国家不同值仍记录异常并取第一条；
- 其他合同级字段按既定规则处理。

## 5. 字段来源优先级

- BG：遗留量 `行销产品维BG中文名称` → 当月订货同名字段 → 要货明细 `BG_CN`；
- 地区部：遗留量 `地区部中文名称` → 要货明细 `地区部`；
- 国家：遗留量 `国家中文名称` → 要货明细 `国家中文名称`；
- 客户群：遗留量 `客户群中文名称` → 要货明细 `签约客户群`；
- 项目名称：遗留量 `交付项目中文名称` → 要货明细同名字段；
- 贸易术语：要货明细；
- 履行供应中心：要货明细 `供应中心简称`。

优先来源为空时继续下一来源。

同一合同+履行供应中心下普通文本字段存在多个不同非空值时，按去重后的原始顺序取第一个有效值，不记录文本冲突异常。

## 7. 标记字段

### 多个供应中心发货

```text
同合同不同有效履行供应中心数 > 1 → Y
否则 → N
```

### 是否解锁备货

读取去重后真实记录中的`备货总控标识`，按原顺序使用 `|` 拼接。例如：`Y|Y|N`。

### 分批发货

```text
完全重复明细去除后，同合同+履行供应中心真实记录数 > 1 → Y
否则 → N
```

### 多次要货

```text
不同有效RPD日期数 > 1 → Y
否则 → N
```

### 分批供应

```text
不同有效CPD日期数 > 1 → Y
否则 → N
```

### 总控标识不一致

同一要货明细行中，备货总控标识和发货总控标识均为有效Y/N但值不同，写入异常清单；不新增输出列。

## 8. 海运周期

贸易术语规范化后：

```text
FCA / FOB / EXW → 5
```

其他贸易术语：

```text
国家 + 履行供应中心
→ 国家运输周期表
→ 运输周期
```

找不到时海运周期为空并记录异常。运输周期显示格式为`#,##0`且底层为非整数浮点时，按Excel显示整数四舍五入，不直接截断。

## 9. 日期聚合与货未发完

同一合同+履行供应中心：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- 最晚ASD = MAX(`ASD日期`)
- 最晚RPD = MAX(`RPD日期`)
- CPD = MAX(`CPD日期`)

空单元格、纯空白、`(空白)`、`#VALUE!`和等价VALUE标记均按无日期处理，不进入异常清单。

货未发完：

```text
最晚RPD为空 → 空
最晚RPD有效、最晚ASD为空 → Y
两者有效且最晚RPD>最晚ASD → Y
两者有效且最晚RPD<=最晚ASD → N
```

正常空值导致无法判断时不记录异常。

## 10. 到货日期

### 到货日期（按RPD）

```text
货未发完 != Y：
  ATA有效 → ATA
  否则ASD和海运周期有效 → ASD+海运周期
  否则 → 空

货未发完 = Y：
  不使用ATA/ASD
  最晚RPD和海运周期有效 → 最晚RPD+海运周期
  否则 → 空
```

### 到货日期（按CPD）

```text
货未发完 != Y：
  ATA有效 → ATA
  否则ASD和海运周期有效 → ASD+海运周期
  否则 → 空

货未发完 = Y：
  不使用ATA/ASD
  CPD和海运周期有效 → CPD+海运周期
  否则 → 空
```

ATA、ASD及对应计划日期全部为空时，不做运算，结果直接为空，不记录异常。存在依赖海运周期的日期路径但周期缺失时，记录运输周期异常并留空。

## 11. 收入年月

- 收入年月（按RPD）= 到货日期（按RPD）的年月；
- 收入年月（按CPD）= 到货日期（按CPD）的年月；
- 到货日期为空时，对应收入年月为空。

## 12. 收入分段类别

每次运行重新计算：

```text
1. 多次要货 = Y → 需判断

2. 多次要货 != Y，ATA或ASD任一有效 → 发未收

3. 多次要货 != Y，ATA/ASD均为空，RPD或CPD任一有效：
   遗留量=0 且 当月新订货=0 → 未录入订货
   遗留量、当月新订货任意一个不为0 → 订未发

4. 多次要货 != Y，ATA/ASD/RPD/CPD全空 → 不要货
```

金额判断使用最终标准化数值，空值和VALUE均按0。

## 13. 三个人工字段

只有以下三列人工维护：

- 是否手工调整收入月份；
- 手工调整收入月份；
- 调整备注。

首次运行或新业务行为空；后续按`合同号 + 履行供应中心`继承上一期值。

## 14. 异常与正常空值

所有可恢复异常写入`异常清单`并继续处理。

不应记录异常的情况：

- 空白字符、空单元格、`(空白)`；
- `#VALUE!`和等价VALUE占位；
- 同业务组普通文本字段多值；
- 当月订货按合同号无匹配；
- 全部候选日期为空而导致到货日期为空。

应记录的关键异常：

- 合同在要货明细完全找不到；
- 国家冲突；
- 同行备货/发货总控标识不同；
- 字段缺失或歧义；
- 非空非法枚举、金额或日期；
- 运输周期缺失或非法；
- 完全重复行被忽略。
