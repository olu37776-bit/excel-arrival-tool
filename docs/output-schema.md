## 2. 输出名称与源字段解耦

输出标题未来可以变化。业务代码只依赖稳定内部字段 ID 和源字段配置；不能依赖输出列名，也不能依赖 Excel 固定列字母。

RPD 已正式确认：源字段为 `RPD日期`，此前 POC/旧文档中的 PRD 属于错误假设，后续代码和测试必须迁移到 RPD。

## 3. 已确认的属性字段来源优先级

- BG：遗留量 → 当月订货 → 要货明细；
- 地区部：遗留量 → 要货明细；
- 国家：遗留量 → 要货明细；
- 客户群：遗留量 → 要货明细；
- 项目名称：遗留量 → 要货明细；
- 贸易术语：要货明细；
- 供应中心：要货明细。

当月订货不参与地区部、客户群、项目名称的回退链。

## 4. 结转类型

### BR-CARRYOVER-001 `[CONFIRMED]`

结转类型只根据**遗留量表自身的 `国家中文名称`**判断，不使用输出“国家”经过回退后的结果。

若遗留量表 `国家中文名称` 属于以下任一国家：

- 阿拉伯联合酋长国
- 巴基斯坦
- 巴西
- 菲律宾
- 马来西亚
- 沙特阿拉伯
- 印度尼西亚

则：

```text
结转类型 = 交付类
```

其他值（包括遗留量表没有该国家值）当前规则为留空。

## 5. 多个供应中心发货

### BR-MULTI-SC-001 `[CONFIRMED]`

按合同号判断：

```text
同一合同号对应的不同“供应中心简称”数量 > 1 → Y
否则 → N
```

该标记是合同级属性，可复制到该合同的每个供应中心输出行。

## 6. 备货/发货总控与分批发货

### BR-STOCK-001 `[PARTIALLY_CONFIRMED]`

`是否解锁备货` 来源于要货明细 `备货总控标识`，源值为 Y/N。

### BR-SHIP-SPLIT-001 `[PARTIALLY_CONFIRMED]`

业务方已确认：`备货总控标识` 与 `发货总控标识` 应同步；同一业务组内若相关总控标识出现多个值，说明存在分批发货。

当前仍需确认“多个值”的精确定义：

- 是指同一 `合同号 + 供应中心` 下同时出现 Y 和 N；
- 还是指存在多条总控记录/多次发货记录，即使值相同也算分批。

在该边界确认前不得自行选一种实现。

日期字段 ATA/ASD/RPD/CPD 属于单次/多次发货记录可能携带的业务日期，不能仅以某一个日期字段非空来判断是否分批发货。

## 7. 多次要货与分批供应

### BR-MULTI-DEMAND-001 `[PARTIALLY_CONFIRMED]`

`多次要货` 与同一 `合同号 + 供应中心` 下 RPD 记录次数有关，输出值为 Y/N。

待确认：应统计“非空 RPD 行数”还是“不同 RPD 日期的数量”。

### BR-SPLIT-SUPPLY-001 `[PARTIALLY_CONFIRMED]`

`分批供应` 由同一 `合同号 + 供应中心` 下 CPD 记录结构判断。

待确认：应统计“非空 CPD 行数”还是“不同 CPD 日期的数量”，以及阈值是否同样为 >1 即 Y。

## 8. 日期与到货计算

同一 `合同号 + 供应中心` 内：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- CPD = MAX(`CPD日期`)

按 RPD 到货日期：

```text
有 ATA → MAX(ATA)
否则有 ASD → MAX(ASD)
否则 → MIN(RPD) + 最终海运周期
```

按 CPD 到货日期：

```text
有 ATA → MAX(ATA)
否则有 ASD → MAX(ASD)
否则 → MAX(CPD) + 最终海运周期
```

ATA/ASD 命中时不加海运周期。收入年月分别取对应到货日期的年月。

## 9. 人工维护字段

以下四列不由本次源表计算，默认从上一轮同一业务记录继承：

- 收入分段类别
- 是否手工调整收入月份
- 手工调整收入月份
- 调整备注

首次出现且上一轮无对应记录时留空。稳定继承键当前候选为 `合同号 + 供应中心`。

## 10. 仍待确认的高优先规则

1. 最终合同全集/输出行如何形成；
2. 同一合同多个供应中心时，遗留量和当月新订货如何放到多行，避免金额重复统计；
3. `是否解锁备货` 在同组有多个 Y/N 值时最终输出取什么；
4. `分批发货` 的“多个值”究竟按不同值还是记录次数判断；
5. `多次要货` 是按 RPD 非空记录数还是不同日期数；
6. `分批供应` 是按 CPD 非空记录数还是不同日期数；
7. 手工调整收入月份是否覆盖某个自动收入年月用于最终统计。
