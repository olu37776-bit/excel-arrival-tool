## 2. 输出名称与源字段解耦

输出标题未来可以变化。业务代码只依赖稳定内部字段 ID 和源字段配置；不能依赖输出列名，也不能依赖 Excel 固定列字母。

例如内部字段 `supply_center`：

- 源字段：要货明细 `供应中心简称`
- 输出显示名：`履行供应中心`
- 运输周期规格表对应源字段：`供应中心`

三个名称可以不同，但都映射到同一稳定业务语义。

RPD 已正式确认：源字段为 `RPD日期`，此前 POC/旧文档中的 PRD 属于错误假设，后续代码和测试必须迁移到 RPD。

## 3. 合同级字段与履行供应中心级字段

### BR-CONTRACT-FIELD-001 `[CONFIRMED]`

`遗留量` 与 `当月新订货` 都是合同级字段：

- 遗留量按合同号从遗留量表取得；
- 当月新订货按合同号从当月订货表取得；
- 它们不按履行供应中心拆分，也不需要分摊；
- 当同一合同因为多个履行供应中心展开成多行时，这两个合同级值随合同复制到对应行。

当月订货表允许整表不提供。未提供时不得阻塞整次运行；`当月新订货` 展示为空还是 0 仍需业务确认。

当前工具不做收入金额汇总，因此不对这些重复展示的合同级金额做求和、分摊或去重统计。

## 4. 已确认的属性字段来源优先级

- BG：遗留量 `行销产品维BG中文名称` → 当月订货 `行销产品维BG中文名称`（若表存在）→ 要货明细 `BG_CN`；
- 地区部：遗留量 → 要货明细；
- 国家：遗留量 → 要货明细；
- 客户群：遗留量 → 要货明细；
- 项目名称：遗留量 → 要货明细；
- 贸易术语：要货明细；
- 履行供应中心：要货明细 `供应中心简称`。

当月订货不参与地区部、客户群、项目名称的回退链。

## 5. 结转类型

### BR-CARRYOVER-001 `[CONFIRMED]`

结转类型只根据**遗留量表自身的 `国家中文名称`**判断，不使用输出“国家”经过回退后的结果。

若遗留量表 `国家中文名称` 属于以下任一国家：

- 阿拉伯联合酋长国
- 巴基斯坦
- 巴西
- 菲律宾
- 马来西亚
- 沙特阿拉伯
- 印度尼西亚

则：

```text
结转类型 = 交付类
```

其他值留空。

## 6. 多个供应中心发货

### BR-MULTI-SC-001 `[CONFIRMED]`

按合同号判断：

```text
同一合同号对应的不同“履行供应中心”数量 > 1 → Y
否则 → N
```

该标记是合同级属性，可复制到该合同的每个履行供应中心输出行。

## 7. 备货/发货总控与分批发货

### BR-STOCK-001 `[PARTIALLY_CONFIRMED]`

`是否解锁备货` 来源于要货明细 `备货总控标识`，源值为 Y/N。

如果同一 `合同号 + 履行供应中心` 下存在多条记录，当前暂不强行压缩为单个 Y/N；先保留每次出现的标识信息，等待后续业务确认最终展示形式。

### BR-SHIP-SPLIT-001 `[CONFIRMED]`

`备货总控标识` 与 `发货总控标识` 应同步。

同一 `合同号 + 履行供应中心` 下：

```text
总控/发货记录数 > 1 → 分批发货 = Y
否则 → N
```

不要求这些记录的 Y/N 值不同。

## 8. 多次要货与分批供应

### BR-MULTI-DEMAND-001 `[CONFIRMED]`

```text
同合同 + 履行供应中心下不同有效 RPD 日期数 > 1 → 多次要货 = Y
否则 → N
```

### BR-SPLIT-SUPPLY-001 `[CONFIRMED]`

```text
同合同 + 履行供应中心下不同有效 CPD 日期数 > 1 → 分批供应 = Y
否则 → N
```

## 9. 日期与到货计算

同一 `合同号 + 履行供应中心` 内：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- CPD = MAX(`CPD日期`)

按 RPD 到货日期：

```text
有 ATA → MAX(ATA)
否则有 ASD → MAX(ASD)
否则 → MIN(RPD) + 最终海运周期
```

按 CPD 到货日期：

```text
有 ATA → MAX(ATA)
否则有 ASD → MAX(ASD)
否则 → MAX(CPD) + 最终海运周期
```

ATA/ASD 命中时不加海运周期。收入年月分别取对应到货日期的年月。

## 10. 收入分段类别

### BR-REVENUE-SEGMENT-001 `[CONFIRMED]`

`收入分段类别` 每次运行重新计算，粒度为：

```text
合同号 + 履行供应中心
```

按以下优先级判断：

```text
1. 多次要货 = Y → 需判断
2. 多次要货 != Y，且 ATA 或 ASD 任一有值 → 发未收
3. 多次要货 != Y，ATA/ASD 为空，且 RPD 或 CPD 任一有值 → 订未发
4. 多次要货 != Y，ATA/ASD/RPD/CPD 全空 → 不要货
```

## 11. 当前工具范围

### BR-SCOPE-001 `[CONFIRMED]`

当前版本先完成：

- 必选源表与可选当月订货表的读取、存在性判断和字段校验；
- 目标基表生成；
- 合同级属性和履行供应中心级属性填充；
- 派生标记；
- 海运周期与到货日期计算；
- 收入年月字段生成；
- 收入分段类别计算；
- 三个人工调整字段跨次继承；
- RPD/CPD 收入年月跨月变化清单。

当前**不做收入金额汇总、收入统计报表或金额聚合**。

## 12. 人工维护字段

以下三列不由本次源表计算，默认从上一轮同一业务记录继承：

- 是否手工调整收入月份
- 手工调整收入月份
- 调整备注

首次运行、或上一轮无对应 `合同号 + 履行供应中心` 记录时，三列均为空。

## 13. 仍待确认的高优先规则

1. 最终合同全集/输出行如何形成；
2. 当月订货表未提供时，`当月新订货` 显示空值还是 0；
3. `是否解锁备货` 在同组多条记录时的最终展示方式；
4. 手工调整收入月份是否覆盖某个自动收入年月用于后续用途；
5. ATA/ASD 已命中时，运输周期规格缺失是否仍作为阻塞错误；
6. RPD/CPD 跨月变化清单是否同时展示提前与延后，以及空→有/有→空是否进入清单。
