## 2. 业务粒度

### 2.1 正常要货业务行

```text
合同号 + 履行供应中心
row_kind = DEMAND_CENTER
```

同一合同存在多个真实履行供应中心时，每个中心输出一行。

### 2.2 无要货明细合同占位行

合同进入合同全集，但要货明细中该合同号匹配数为0时：

```text
合同号 + 空履行供应中心
row_kind = CONTRACT_ONLY_NO_DEMAND
```

该合同必须保留一行，不记录合同未找到或供应中心缺失异常。

同一合同最多一条无要货占位行。同一期同一合同不得同时输出正常中心行和无要货占位行。

合同全集：

```text
当月订货存在且成功读取：
遗留量 ∪ 当月订货 ∪ 要货明细

当月订货未提供：
遗留量 ∪ 要货明细
```

## 3. 合同级字段

遗留量、当月新订货、BG、地区部、国家、客户群、项目名称等按合同号取得。

同一合同多个履行供应中心时，规范化后精确等于`深供`的行承载遗留量、当月新订货及收入预测，其他中心三列显示0。找不到深供时不擅自选择其他中心，保留原展示并记录`MULTI_CENTER_DEEP_SUPPLY_NOT_FOUND`。

无要货占位行仍保留所有可取得的合同级字段。

## 4. 金额字段输出

`遗留量`、`当月新订货`和系统计算的`收入预测`始终为数值：

- 正常数值按统一两位小数业务精度输出；
- 空单元格、纯空白、`(空白)`、`#VALUE!`及等价VALUE标记输出0；
- 整个当月订货文件未提供时，当月新订货输出0；
- 文件存在但合同无匹配时输出0；
- 非空非法金额记录异常并降级为0。

金额使用：

```text
Decimal(str(value))
→ ROUND_HALF_UP量化到0.01
```

基表、收入分段和后续汇总使用同一个规范化金额值。

## 5. 同合同多记录与字段来源

遗留量和存在时的当月订货：

- 完全重复先去重；
- 去重后仍多行，按原表顺序取第一条；
- 当前不求和、不取最大、不分摊；
- 国家冲突继续记录异常并使用第一条。

字段来源：

- BG：遗留量 → 当月订货（若存在且有值） → 要货明细；
- 地区部：遗留量 → 要货明细；
- 国家：遗留量 → 要货明细；
- 客户群：遗留量 → 要货明细；
- 项目名称：遗留量 → 要货明细；
- 贸易术语、履行供应中心：要货明细。

同一合同+履行供应中心下普通文本多值时，取第一条有效值，不记录文本冲突异常。

## 6. 结转类型

先按`遗留量国家 → 要货明细国家`得到最终解析国家，再以其规范化identity判断。以下七国输出`交付类`：

- 阿拉伯联合酋长国
- 巴基斯坦
- 巴西
- 菲律宾
- 马来西亚
- 沙特阿拉伯
- 印度尼西亚

匹配规范见`DR-004`。

合法国家别名必须通过配置中的显式`alias → canonical`映射处理，不做模糊匹配。当前印尼别名包括`印尼`、`印度尼西亚共和国`和`印度尼西亚（印尼）`，均映射到`印度尼西亚`。国家展示仍保留最终解析的原始业务名称，别名只用于结转类型判断。

## 7. 标记字段

### 7.1 多个供应中心发货

```text
同合同不同有效履行供应中心数 > 1 → Y
否则 → N
```

无要货占位行为N。

### 7.2 是否解锁备货

来源：同一合同+履行供应中心下，完全重复去除后的`备货总控标识`。

仅有效Y/N参与计算：

```text
无有效Y/N → 空
全部为Y → 未解锁
全部为N → 已解锁
同时存在Y和N → 部分解锁
```

旧的`Y|Y|N`拼接规则废止。

空白/VALUE忽略；非法非空值记录`INVALID_ENUM_VALUE`并排除。备货与发货总控标识不一致不再生成`CONTROL_FLAG_MISMATCH`，最终三态只由备货总控标识决定。

无要货占位行输出空。

### 7.3 分批发货

```text
完全重复明细去除后，同合同+履行供应中心真实记录数 > 1 → Y
否则 → N
```

### 7.4 多次要货

```text
不同有效RPD日期数 > 1 → Y
否则 → N
```

### 7.5 分批供应

```text
不同有效CPD日期数 > 1 → Y
否则 → N
```

无要货占位行的分批发货、多次要货、分批供应均为N。

## 8. 海运周期

```text
FCA / FOB / EXW → 5
其他术语 → 国家 + 履行供应中心查国家运输周期表
```

找不到或不可用时，按`DR-004`分型记录异常。

无要货占位行不查询运输周期，海运周期为空，不产生运输周期异常。

## 9. 日期聚合与货未发完

正常要货业务行：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- 最晚ASD = MAX(`ASD日期`)
- 最晚RPD = MAX(`RPD日期`)
- CPD = MAX(`CPD日期`)

标准化空值不参与聚合。

货未发完：

```text
最晚RPD为空 → 空
最晚RPD有效、最晚ASD为空 → Y
两者有效且最晚RPD>最晚ASD → Y
两者有效且最晚RPD<=最晚ASD → N
```

无要货占位行所有日期和货未发完均为空。

## 10. 到货日期

### 按RPD

```text
货未发完 != Y：
  ATA有效 → ATA
  否则ASD和海运周期有效 → ASD+海运周期
  否则 → 空

货未发完 = Y：
  最晚RPD和海运周期有效 → 最晚RPD+海运周期
  否则 → 空
```

### 按CPD

```text
货未发完 != Y：
  ATA有效 → ATA
  否则ASD和海运周期有效 → ASD+海运周期
  否则 → 空

货未发完 = Y：
  CPD和海运周期有效 → CPD+海运周期
  否则 → 空
```

无要货占位行不执行到货日期计算，两套到货日期和收入年月均为空。

## 11. 收入分段类别

### 11.1 无要货占位行最高优先级

```text
row_kind = CONTRACT_ONLY_NO_DEMAND
或 demand_detail_match_count = 0
→ 不要货
```

即使遗留量或当月新订货非0，也仍为`不要货`。该分类必须来自显式领域状态，不能只依赖日期全空。

### 11.2 正常要货业务行

```text
1. 多次要货=Y → 需判断
2. 否则ATA或ASD有效 → 发未收
3. 否则RPD或CPD有效：
   两项金额均为0 → 未录入订货
   任一金额非0 → 订未发
4. 否则 → 不要货
```

## 12. 六个人工字段

首次运行或新业务行为空；后续按稳定业务键继承。

- `调整收入分段类别`：允许任意普通Excel值，不做枚举或类型限制；不改写系统计算的收入分段；
- `是否手工调整预测`：沿用既有人工标识；
- `调整月份（按RPD）`：`YYYY-MM`文本，Excel格式为`@`；
- `调整月份（按CPD）`：`YYYY-MM`文本，Excel格式为`@`；
- `调整金额`：Decimal两位小数，允许正数、负数和明确0；
- `调整备注`：人工文本。

旧显示名通过稳定字段ID或兼容别名读取；明确数值0不得变为空白。`收入预测`不是人工字段，不从上期继承。

- 正常中心行：合同号+履行供应中心；
- 无要货占位行：合同号+空履行供应中心。

无要货占位行后续恢复真实中心时，不把空中心行的人工值自动复制给真实中心。

人工月份若从上期读到Excel日期/日期时间，统一规范化为`YYYY-MM`；其他非空非法月份记录`INVALID_PREVIOUS_MANUAL_MONTH`并按空白处理。非法人工金额记录`INVALID_PREVIOUS_MANUAL_AMOUNT`。`调整收入分段类别`不生成Y/N或类别枚举限制异常；Excel error类型沿用通用安全空值处理。以上规则均不得把明确数值0静默改为空白。

## 13. 跨期与差异清单

详见`docs/comparison-output.md`和`DR-006`。

- 有要货→不要货：RPD/CPD清单方向=`变为不要货`；
- 不要货→有要货：方向=`恢复要货`；
- 月份为空时仍需发现状态变化；
- 无要货占位行不进入供应需要提拉诉求清单。
- RPD跨月变化、CPD跨月变化和供应提拉三张表均在`国家`之后输出`结转类型`。

## 14. 异常与正常缺省

不应记录异常：

- 整个当月订货文件未提供；
- 空白、`(空白)`、VALUE占位；
- 普通文本多值；
- 当月订货合同无匹配；
- 无要货明细合同占位行及其空履约字段；
- 全部候选日期为空而自然无法计算到货日期。

应记录的关键异常：

- 已提供文件但业务Sheet无法识别/歧义；
- 要货明细存在合同但无有效履行供应中心；
- 国家冲突；
- 非空非法枚举、金额、日期、运输周期；
- 国家+中心无运输周期组合；
- 完全重复行被忽略。
