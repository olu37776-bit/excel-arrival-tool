# 地区收入汇总（v0.11.0，Issue #44）

覆盖此前按月拆表和累计的设计，以用户最后要求为准。

## 输出合同

固定两张原生透视：RPD地区收入汇总、CPD地区收入汇总。第一列地区部，月份按YYYY-MM向右排列，每个月订未发、发未收、交未验、其他、小计。底行为小计；无累计、无GUI月选项。月份取两种最终收入年月的有效值并集，保留跨年完整年月，支持超过12个月。空数据不虚构月份。

RPD按最终RPD年月，CPD按最终CPD年月，均汇总最终收入预测。非三种标准类别归其他，负数和明确0正常参与。无有效年月或金额不参与金额汇总。每月小计是四类之和，双击每个金额展开准确的业务条目，不重复。

## 原生筛选与编辑

基表、汇总都无工作表保护；原生透视字段标题和筛选按钮可见。用户可直接用基表筛选、排序及自建透视。金额调整在基表黄色人工列进行，四个最终字段保留公式和初始缓存。自动计算模式下公式更新后，数据→全部刷新更新原生透视；Excel的应用级手动计算模式仍需用户切回自动。Issue #45缺少实机样本，不以本次测试代替用户环境确认。

两张表共享45列的隐藏明细源，40列基表原值及5列辅助信息。每个业务行分RPD/CPD，每种口径两条分类/小计记录，共4N条，另有5M条被口径筛选排除的schema占位记录，固定列与缺数据月份也保留五个类别。隐藏明细源不作为用户自建透视来源。用户修改现有行到新月份后刷新，新增月份按年月排序。

## 验证

静态核对全部月份、地区、分类及小计的金额与缓存明细；原生引擎编辑人工输入后，在任何刷新或强制重算前读取四个最终字段，随后原生刷新并检查每个金额的Show Details。新增月份、布尔/零金额、负数、清空恢复覆盖。Microsoft Open XML SDK独立校验XLSX结构；Windows构建后运行EXE与真实Tk窗口smoke。自动引擎是LibreOffice，不冒充微软Excel桌面实机验收。
