# v0.11.5 收入空间与固定行高（Issue #55）

## 用户需求与实现

- 全部Sheet明确固定数据行高22磅，业务表头32磅，同时设置默认行高与customHeight。保持工作表可编辑，不启用保护。备注长文本/换行不自动撑高，长备注可在编辑栏查看；用户仍可主动改行高。
- 基表D列显示名改为“收入空间”，保留内部ID `revenue_forecast`；旧显示名“收入预测”继续兼容。
- AM“最终收入预测”后新增AN“收入空间差额”，备注移至AO。公式按行引用D－AM，两位小数，保留正负号；数值无效时显示待修正提示。初始缓存由Python独立计算；后续随Excel自动计算更新。差额不作为上期输入。
- RPD、CPD跨月变化及供应提拉三张清单增加D列“收入空间”，由该行遗留量＋当月新订货计算。覆盖正常变化、取消、变为不要货、恢复要货；保持既有金额承载规则。
- 收入空间维持既有系统数值语义，不额外引入大规模辅助公式。基表每行由4个最终公式增加为5个（含差额），保持自动计算、不强制全量重算，不生成或继承用户透视。

## 验证范围

1. 新41列布局与筛选范围、正/零/负差额、金额舍入、无效人工金额及公式初始缓存。
2. 所有Sheet及空表默认行高、XML逐行customHeight、未受保护；备注换行保存后保持设置。
3. 旧40列上期结果（元数据有/无）、旧收入预测表头、旧备注位置、人工0/False/月值；原输入不改写，新差额重新计算。
4. 三张辅助页收入空间与每行两项金额之和一致，含历史取消和合同要货状态切换，不取旧预测值。
5. 独立LibreOffice引擎实际打开后编辑/清空人工金额，检查无需手动重算即更新差额；输入多行长备注、保存并重新打开验证固定行高。
6. Windows打包EXE smoke检查全部Sheet行高、新列布局、差额缓存及三个辅助页收入空间，并保留已有上期兼容检查。
