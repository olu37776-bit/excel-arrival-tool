## 2. 无要货合同验证

- 遗留量、当月订货任一或同时包含合同，而要货明细完全无该合同时，只生成一条占位行。
- 占位行键为“合同号 + 空履行供应中心”，不会虚构供应中心文本。
- 合同级字段正常填写；履约字段、海运周期、日期、到货日期和收入年月为空。
- 多个供应中心发货、分批发货、多次要货、分批供应均为 `N`。
- 收入分段策略优先读取 `row_kind=CONTRACT_ONLY_NO_DEMAND`，即使金额非零或传入日期/多次要货条件，仍返回“不要货”。
- 不产生合同未找到、供应中心缺失或海运周期异常。
- 占位行不进入 RPD 变化、CPD 变化或供应提拉清单。
- 三个人工字段只在“合同号 + 空履行供应中心”之间继承；后续真实供应中心不会继承占位行人工值。
- 要货明细已有合同但供应中心全为空时，仍按数据质量异常处理，不误建占位行。
