## 2. 当前已冻结的核心规则

### 输入

一个 Excel 工作簿，多 Sheet：

1. 遗留量
2. 当月订货（可选）
3. 要货明细
4. 国家运输周期

### 合同集合

遗留量、当月订货（存在时）、要货明细三个业务表合同号合并去重。

### 最终粒度

```text
合同号 + 履行供应中心
```

### 合同级字段

遗留量、当月新订货及主要合同属性跟合同走。同合同多供应中心时复制展示。

同合同多行：完全重复先去重，剩余默认取第一条；不同非空值写异常但继续。

### 日期

同合同+履行供应中心：

- ATA 最大
- ASD 最大
- RPD 最小
- CPD 最大

### 海运周期

```text
贸易术语为 FCA / FOB / EXW → 5天
否则 国家 + 履行供应中心 → 国家运输周期表 → 运输周期
```

### 到货日期

按RPD：ATA → ASD → RPD+海运周期。

按CPD：ATA → ASD → CPD+海运周期。

ATA/ASD 命中时不依赖海运周期。

### 派生标记

- 多个供应中心发货：同合同不同中心数>1；
- 分批发货：完全重复行去除后，同合同+中心真实记录数>1；
- 多次要货：不同有效RPD日期数>1；
- 分批供应：不同有效CPD日期数>1。

### 收入分段类别

```text
多次要货=Y → 需判断
否则 ATA/ASD 任一有效 → 发未收
否则 RPD/CPD 任一有效 → 订未发
否则 → 不要货
```

### 人工字段

只有以下三列人工维护：

- 是否手工调整收入月份
- 手工调整收入月份
- 调整备注

首次为空，后续按合同号+履行供应中心继承。

### 跨月变化

RPD、CPD 分两个 Sheet，比较两期自动收入年月：

- 延后列出；
- 提前列出；
- 空→有列出为新增；
- 有→空列出为取消；
- 两期都空不列；
- 输出变化方向和变化月数。

### 异常

所有可恢复的业务/数据异常均不终止整批：

- 写入异常清单；
- 明确原因；
- 能算的继续算；
- 无法算的派生字段留空。

只有工作簿无法打开等无法继续读取的技术故障可能终止运行。

## 3. 字段解耦审查

已确认采用三层：

```text
源字段名
→ 稳定内部字段ID
→ 输出显示名
```

BG 和履行供应中心已经验证这种设计的必要性。

所有字段统一执行：

```text
精确匹配优先
→ 精确失败后包含匹配
→ 唯一命中才接受
→ 多命中写异常
```

没有字段级 contains 白名单。

## 4. 完全重复数据审查

完全重复脏数据不得参与业务次数计算。

处理顺序必须是：

```text
读取
→ 规范化
→ 识别完全重复行
→ 只保留第一条参与业务
→ 记录重复异常
→ 再计算分批/多次/日期聚合
```

这可以避免完全重复行被误判为分批发货。
