## 2. 本地资料已确认事实

1. 遗留量、当月订货、要货明细、国家运输周期来自四个独立 Excel 文件，不在同一个工作簿。
2. 当月订货源字段实际为 `设备订货(不含VAT)`，括号为半角；NFKC 可与全角括号配置统一。
3. ASD 日期约 39% 为 Excel `#VALUE!` 错误值，应记异常并排除。
4. ATA 约 51% 为文本占位 `(空白)`；全角括号形式经 NFKC 后同样按空值处理。
5. 部分运输周期单元格显示为整数，但底层为非整数浮点，显示格式为 `#,##0`；应按显示结果四舍五入取整。

上述比例是本次本地资料观测，不是固定业务阈值；实现不得硬编码 39% 或 51%。

## 3. 当前冻结规则

### 输入与合同集合

- 四个独立 Excel 源文件分别映射四个业务角色。
- 合同全集仍由遗留量、当月订货、要货明细三个源表的合同号并集去重。
- 某合同在当月订货中无匹配记录时，当月新订货为空，不填 0。

### 业务粒度

```text
合同号 + 履行供应中心
```

### 日期与到货日期

- ATA = MAX；
- ASD = MAX；
- RPD = MIN；
- 最晚ASD = MAX(ASD)；
- 最晚RPD = MAX(RPD)；
- CPD = MAX。

```text
按RPD：ATA → ASD+海运周期 → RPD+海运周期
按CPD：ATA → ASD+海运周期 → CPD+海运周期
```

只有 ATA 路径不依赖海运周期。

### 货未发完

```text
最晚RPD > 最晚ASD → Y
两者有效且最晚RPD <= 最晚ASD → N
任一缺失或非法 → 留空并记录原因
```

### 基表与人工字段

- 基表从 29 列扩展为 32 列；
- 多次要货后依次增加最晚ASD、最晚RPD、货未发完；
- 三个人工字段仍为是否手工调整收入月份、手工调整收入月份、调整备注；
- 三个人工字段首次为空，后续按合同号+履行供应中心继承。

### 输出清单

结果工作簿至少包含：

1. 基表
2. RPD跨月变化
3. CPD跨月变化
4. 供应需要提拉诉求清单粗表
5. 异常清单

`供应需要提拉诉求清单粗表`比较同一期两套自动收入年月；两者均有效且绝对偏差达到 1 个月及以上时入表。

## 4. 字段解耦与异常策略

继续采用：

```text
独立源文件/源字段名
```
