# 旧版上期结果新增字段缺值（Issue #40）

## 已复现的问题

v0.9.0 生成的四个最终字段包含 Excel 公式，但没有缓存计算值。
未执行重算的阅读端或 data_only 读取会看到空值；新建结果和导入旧表均受影响。
自动字段及旧表人工字段的继承不依赖这四列，问题发生在文件输出阶段。

## v0.9.1 修复

生成文件时，在四个最终字段中同时保存原公式与本次计算值。
按实际类型保存金额、年月、文本和布尔值；0、False 不作空值处理。
保留打开重算、自动计算和人工字段优先规则。
只修改基表中指定公式单元格的 OOXML 类型和值，其他压缩包成员原样保留。
使用同目录临时文件，全部写入成功后替换输出文件。

旧表缺少新增系统列时，本期源数据仍补算自动收入预测、最终字段，并新建两张汇总表。
人工调整列在旧表中不存在时保持空白，最终字段回退到本期自动值。
原有人工调整金额及备注继续继承。

## 回归范围

- 旧32列布局缺少收入预测和部分人工字段，及旧36列布局缺少四个最终字段；两者均移除新汇总表。
- 生成后直接 data_only 读取，检查自动回退、人工0/False、RPD/CPD年月及两张原生透视表。
- 原公式验证数据集覆盖月份、金额、无效输入提示等；另检查XML特殊字符。
- 原生计算引擎继续验证编辑、清空人工字段及更改汇总月份后的重算与明细。
- Windows EXE自检增加四个最终字段计算值读回。

用户的实际旧文件尚未提供，本次修复针对已复现的空缓存问题。
用户后续在第三方程序中编辑并保存，仍由该程序负责更新公式缓存。
