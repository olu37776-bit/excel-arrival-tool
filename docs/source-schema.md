## 1. 输入源文件

真实输入为四个彼此独立的 Excel 文件，每个文件承载一个固定业务角色：

1. 遗留量；
2. 当月订货；
3. 要货明细；
4. 国家运输周期。

不得要求用户先把四张源表合并到一个工作簿。四个文件均需可读取；某个合同允许在当月订货表中没有匹配记录。

## 6. 字段来源优先级

- BG：遗留量 `行销产品维BG中文名称` → 当月订货同名字段 → 要货明细 `BG_CN`；
- 地区部：遗留量 `地区部中文名称` → 要货明细 `地区部`；
- 国家：遗留量 `国家中文名称` → 要货明细同名字段；
- 客户群：遗留量 `客户群中文名称` → 要货明细 `签约客户群`；
- 项目名称：遗留量 `交付项目中文名称` → 要货明细同名字段。

优先来源标准化后为空时继续下一来源。

## 7. 三层解耦

实现必须区分：

1. 稳定内部字段 ID；
2. 每个独立源表的实际字段名；
3. 输出显示名称。

示例：

```text
内部：supply_center
要货明细：供应中心简称
国家运输周期：供应中心
输出：履行供应中心
```

```text
内部：bg
遗留量/当月订货：行销产品维BG中文名称
要货明细：BG_CN
输出：BG
```

源表头变化只修改映射；输出名称变化只修改输出配置；领域规则只使用内部字段 ID。

## 8. 统一字段匹配机制

所有字段使用同一套机制：

1. Unicode NFKC；
2. 去首尾空白；
3. 折叠连续空格、制表符和换行；
4. 英文字母大小写不敏感；
5. canonical/alias 精确匹配优先；
6. 精确未命中时执行包含匹配；
7. 包含匹配只有唯一候选时成功；
8. 多候选记录 `AMBIGUOUS_FIELD`，该字段本次不可用但整批继续；
9. 未命中记录 `MISSING_FIELD`；
10. 禁止相似度、编辑距离和“最像字段”自动选择。

## 9. 全局空值标准化

### FS-NULL-001 `[CONFIRMED]`

以下原始值统一转为内部空值，不记录异常：

- Excel 空单元格或 Python `None`；
- 只含空格、制表符、换行等空白字符的文本；
- NFKC、去空白后等于 `(空白)` 的占位文本；
- Excel 错误值 `#VALUE!`；
- 读取后等价的 `VALUE`、`#VALUE`、`#VALUE!` 文本，忽略大小写。

其他 Excel 错误类型不自动归为空值，仍按字段类型记录异常。

## 10. 数据类型与标准化

### 10.1 合同号

合同号按文本处理：

- 保留前导零；
- 去首尾空白；
- 不把浮点和科学计数法静默转换成合同号；
- 标准化为空的合同号不进入合同集合；
- 空白/VALUE占位本身不记录异常。

### 10.2 金额

`legacy_amount`、`monthly_new_order`最终标准化为数值：

- 正常数字 → 对应数值；
- 空值、空白占位、VALUE占位、合同无匹配 → `0`；
- 其他非空且无法解析的值 → 记录 `INVALID_AMOUNT`，本次使用 `0`。

金额字段不得在领域模型中保留 `None`，以保证汇总和收入分段判断稳定。

### 10.3 日期

ATA、ASD、RPD、CPD接受 Excel 日期值或明确可解析的日期文本：

- 标准化空值和VALUE占位 → `None`，不记录异常；
- 正常日期 → `date`；
- 其他非空且无法解析的值 → 记录 `INVALID_DATE` 并排除聚合。

### 10.4 普通文本

普通文本标准化为空时保留空值，不记录异常。非空文本仅做有限规范化，不删除有业务意义的中文、数字、下划线、连字符或括号内容。

### 10.5 Y/N标识

备货总控标识、发货总控标识：

- 空值允许，不记录异常；
- 非空值去空白并转大写；
- `Y`、`N`为有效值；
- 其他非空值记录 `INVALID_ENUM_VALUE`。

同一要货明细行中，两字段均为有效Y/N但不同，记录 `CONTROL_FLAG_MISMATCH`。

### 10.6 运输周期

运输周期应为非负整数自然日：

- 单元格显示格式为 `#,##0`时，按Excel零位小数显示结果四舍五入；
- 不直接截断底层浮点；
- 标准化空值返回空周期；
- 其他非法非空值记录 `INVALID_TRANSIT_DAYS`。

## 11. 重复与基数

### 11.1 完全重复行

四个源表均识别完全重复行：

- 只保留第一条参与业务计算；
- 记录 `DUPLICATE_ROW_IGNORED`；
- 被忽略行不增加分批发货、多次要货、分批供应或多个供应中心数量。

### 11.2 遗留量/当月订货同合同多行

完全重复去除后，同一合同仍有多行：

- 按原表顺序取第一条；
- 当前不求和、不取最大、不分摊；
- 国家存在不同非空值时记录国家冲突；
- 其他字段按当前输出规则处理。

### 11.3 要货明细多行

同一`合同号 + 履行供应中心`允许多条真实记录，用于日期聚合和派生标记。完全重复必须先去除。

同组普通文本字段出现多个不同非空值时：

- 按原始顺序取第一条有效值；
- 不记录文本冲突异常。

### 11.4 国家运输周期重复键

同一`国家 + 供应中心`多行：

- 完全重复先去重；
- 仍有多个不同周期时取第一条并记录冲突；
- 不阻塞整批。

## 12. 合同全集与要货明细匹配

合同全集来自：

```text
遗留量合同号 ∪ 当月订货合同号 ∪ 要货明细合同号
```

若合同来自遗留量或当月订货，但要货明细中零匹配：

- 记录 `CONTRACT_NOT_FOUND_IN_DEMAND_DETAIL`；
- 不生成正常业务行；
- 异常消息明确为“要货明细未找到该合同号”。

不得仅写成“没有可用履行供应中心”。

## 13. 海运周期数据使用

贸易术语为`FCA`、`FOB`、`EXW`时，海运周期直接为5天，不查规格表。

其他贸易术语按：

```text
国家 + 履行供应中心
→ 国家运输周期表
→ 运输周期
```

查不到时记录异常并返回空周期。
