## 2. 当前目标与非目标

工具读取本期源Excel，生成合同到货与收入月份基表、跨期变化、供应差异和异常清单。

当前包括：

- 源文件、业务Sheet和字段识别；
- 合同全集生成；
- 合同级与履行供应中心级数据填充；
- 重复数据去重；
- 日期聚合、海运周期和两套到货日期；
- 派生标记、收入分段和人工字段继承；
- RPD/CPD跨期变化；
- 同期RPD/CPD收入年月差异；
- 异常清单。

当前不包括：

- 正式收入金额汇总报表；
- 装运排程、运输优化或资源规划；
- 必须输出VLOOKUP公式；
- 向公共仓库提交真实业务数据。

## 3. 输入源文件

输入角色：

```text
遗留量          必选
当月订货        可选
要货明细        必选
国家运输周期    必选
上一次成功结果  可选
```

四类业务源是彼此独立的Excel文件，不要求合并为一个工作簿。

### 3.1 当月订货未提供

属于正常运行模式：

- 不打开文件、不定位Sheet、不报缺文件/缺字段异常；
- 合同全集不包含当月订货来源；
- 所有业务行`当月新订货=0`；
- BG回退跳过当月订货来源。

### 3.2 当月订货已提供

必须真实解析：

- 业务Sheet可叫`Sheet1/Sheet2/Sheet3`等自动名称；
- 按字段契约识别，不依赖固定Sheet名；
- 文件已提供但无法识别，不得伪装成“未提供”；
- 某合同无匹配时，当月新订货=0且不报异常。

其他三个必选源文件同样按字段契约定位业务Sheet。

## 4. 三层解耦与字段匹配

必须区分：

1. 源表实际字段名；
2. 稳定内部字段ID；
3. 输出显示名。

示例：

```text
内部：supply_center
要货明细：供应中心简称
运输周期表：供应中心
输出：履行供应中心
```

```text
内部：bg
遗留量/当月订货：行销产品维BG中文名称
要货明细：BG_CN
输出：BG
```

统一字段匹配：

1. Unicode NFKC和空白规范化；
2. canonical/alias精确匹配；
3. 精确未命中时执行包含匹配；
4. 包含匹配必须唯一；
5. 多候选记录歧义，不自动猜测；
6. 禁止编辑距离或相似度选“最像字段”。

## 5. 合同全集与业务粒度

合同全集动态形成：

```text
当月订货未提供：
遗留量合同号 ∪ 要货明细合同号

当月订货已提供且可用：
遗留量合同号 ∪ 当月订货合同号 ∪ 要货明细合同号
```

### 5.1 正常要货行

```text
合同号 + 履行供应中心
row_kind = DEMAND_CENTER
```

同一合同多个真实履行供应中心时，每个中心一行。

### 5.2 无要货明细合同占位行

合同进入全集，但要货明细中该合同号匹配记录数为0：

```text
合同号 + 空履行供应中心
row_kind = CONTRACT_ONLY_NO_DEMAND
```

该合同必须保留一行，收入分段显式为`不要货`。这不是异常。

不得产生：

- `CONTRACT_NOT_FOUND_IN_DEMAND_DETAIL`；
- `MISSING_SUPPLY_CENTER`；
- 海运周期缺失或日期缺失异常。

### 5.3 有合同记录但供应中心为空

要货明细中存在该合同，但所有匹配行没有有效履行供应中心：

- 不等同于无要货；
- 属于要货明细数据不完整；
- 按数据质量规则记录异常；
- 不虚构供应中心。

## 6. 合同级字段和来源优先级

合同级字段跟随合同，不按履行供应中心拆分。多中心时复制展示。

来源：

- 遗留量：遗留量`设备订未收-新`；
- 当月新订货：当月订货`设备订货(不含VAT)`；
- BG：遗留量 → 当月订货（若存在且有值） → 要货明细；
- 地区部：遗留量 → 要货明细；
- 国家：遗留量 → 要货明细；
- 客户群：遗留量 → 要货明细；
- 项目名称：遗留量 → 要货明细；
- 贸易术语、履行供应中心：要货明细。

同合同多行：

- 完全重复先去重；
- 去重后按原始顺序取第一条；
- 当前不求和、不取最大、不分摊；
- 同一合同国家冲突记录异常并继续使用第一条；
- 同合同+中心的普通文本多值取第一条，不报文本冲突。

## 7. 空值、VALUE和金额精度

以下按业务空值安静处理：

- 空单元格、空字符串；
- 半角/全角空格、制表符、换行；
- `(空白)`；
- `#VALUE!`、`VALUE`、`#VALUE`等价标记。

类型结果：

- 金额 → 0；
- 日期 → None；
- 文本/标识 → 空；
- 运输周期 → 空。

金额统一：

```text
Decimal(str(raw_value))
→ ROUND_HALF_UP量化到0.01
```

量化后0.00才是业务0。原始极小浮点残留量化为0时不报异常。

基表、收入分段和后续汇总使用同一个规范化金额。

## 8. 重复数据

四类源表均识别完全重复行：

- 只保留第一条参与计算；
- 记录`DUPLICATE_ROW_IGNORED`；
- 不得制造分批发货、多次要货、分批供应或多个供应中心。

## 9. 结转类型

先按`遗留量国家 → 要货明细国家`得到最终解析国家，再按国家identity规范化判断。以下七国输出`交付类`：

- 阿拉伯联合酋长国
- 巴基斯坦
- 巴西
- 菲律宾
- 马来西亚
- 沙特阿拉伯
- 印度尼西亚

国家匹配执行NFKC、空白/换行/常见零宽格式字符清理；合法别名使用显式alias，不使用模糊猜测。

## 10. 要货标记与解锁备货

### 10.1 多个供应中心发货

```text
同合同不同有效履行供应中心数>1 → Y
否则 → N
```

### 10.2 分批发货

```text
去完全重复后，同合同+中心真实记录数>1 → Y
否则 → N
```

### 10.3 多次要货

```text
不同有效RPD日期数>1 → Y
否则 → N
```

### 10.4 分批供应

```text
不同有效CPD日期数>1 → Y
否则 → N
```

### 10.5 是否解锁备货

来源仅为去重后真实记录的`备货总控标识`。

```text
无有效Y/N → 空
全部Y → 未解锁
全部N → 已解锁
同时存在Y和N → 部分解锁
```

旧Y/N拼接规则废止。非法非空标识记录异常并排除；备货/发货总控标识不同不再生成`CONTROL_FLAG_MISMATCH`，最终三态仅由备货总控标识决定。

无要货占位行：多个供应中心发货、分批发货、多次要货、分批供应均为N，是否解锁备货为空。

## 11. 海运周期

贸易术语规范化后：

```text
FCA / FOB / EXW → 5天
其他 → 国家 + 履行供应中心查国家运输周期表
```

查表失败必须分型：

- 国家为空 → `TRANSIT_COUNTRY_MISSING`；
- 国家+中心无组合 → `TRANSIT_NOT_FOUND`；
- 组合存在但周期无可用值 → `TRANSIT_VALUE_UNAVAILABLE`；
- 非空非法周期 → `INVALID_TRANSIT_DAYS`。

异常需包含合同号、国家、履行供应中心、查找组合/原值和原因。

无要货占位行不查运输周期。

## 12. 日期聚合与货未发完

同合同+履行供应中心：

- ATA = MAX(`天_ATA`)
- ASD = MAX(`ASD日期`)
- RPD = MIN(`RPD日期`)
- 最晚ASD = MAX(`ASD日期`)
- 最晚RPD = MAX(`RPD日期`)
- CPD = MAX(`CPD日期`)

货未发完：

```text
最晚RPD为空 → 空
最晚RPD有效、最晚ASD为空 → Y
两者有效且最晚RPD>最晚ASD → Y
两者有效且最晚RPD<=最晚ASD → N
```

## 13. 到货日期和收入年月

### 按RPD

```text
货未发完 != Y：
  ATA → ATA
  否则ASD+海运周期
  否则空

货未发完 = Y：
  最晚RPD+海运周期
  缺必要值则空
```

### 按CPD

```text
货未发完 != Y：
  ATA → ATA
  否则ASD+海运周期
  否则空

货未发完 = Y：
  CPD+海运周期
  缺必要值则空
```

收入年月取对应到货日期的`YYYY-MM`。

无要货占位行不执行海运周期、日期聚合和到货日期计算，相关字段均为空。

## 14. 收入分段类别

最高优先级：

```text
row_kind=CONTRACT_ONLY_NO_DEMAND
或 demand_detail_match_count=0
→ 不要货
```

即使遗留量或当月新订货非0，也仍为`不要货`。必须由显式领域状态决定，不得只靠日期全空偶然分类。

正常要货行：

```text
1. 多次要货=Y → 需判断
2. 否则ATA或ASD有效 → 发未收
3. 否则RPD或CPD有效：
   遗留量=0且当月新订货=0 → 未录入订货
   任一金额非0 → 订未发
4. 否则 → 不要货
```

## 15. 六个人工字段

仅以下六列人工维护：

- 调整收入分段类别；
- 是否手工调整预测；
- 调整月份（按RPD）；
- 调整月份（按CPD）；
- 调整金额；
- 调整备注。

`调整收入分段类别`允许用户自由填写任意普通Excel值，工具不做枚举、类型或语义判断，也不反向覆盖系统计算的收入分段；空白与数值0、布尔值等实际值必须区分。`调整月份（按RPD）/调整月份（按CPD）`为`YYYY-MM`文本；`调整金额`为Decimal两位小数，空白与明确0必须区分。显示名称变化不改变稳定字段ID。`收入预测`由系统按当前行最终展示的`遗留量+当月新订货`计算，不属于人工字段，也不从上期继承。

首次或新业务键为空；后续继承：

- 正常行：合同号+履行供应中心；
- 无要货占位行：合同号+空履行供应中心。

空中心占位行的人工值不得自动复制给后续真实中心。

RPD跨月变化、CPD跨月变化和供应需要提拉诉求清单粗表均在国家之后输出结转类型。

## 16. RPD/CPD跨期变化

普通正常行业务键按自动收入年月比较：

- 延后、提前；
- 上期空→本期有：新增；
- 上期有→本期空：取消。

无要货状态必须显式比较：

```text
上期有要货 + 本期不要货
→ 两张清单均输出“变为不要货”

上期不要货 + 本期有要货
→ 两张清单均输出“恢复要货”
```

即使相应收入年月为空，也必须发现状态变化。

多中心变为不要货时，每个上期真实中心分别可追溯。状态事件优先于普通新增/取消，不得重复。

无要货占位行不进入供应需要提拉诉求清单。

## 17. 输出工作簿

至少包含：

1. 基表
2. RPD跨月变化
3. CPD跨月变化
4. 供应需要提拉诉求清单粗表
5. 异常清单

所有可见Sheet保留筛选下拉、冻结首行，并支持Windows桌面Excel`数据→清除`一次恢复全部数据。

## 18. 异常原则

可恢复异常：

- 写入异常清单；
- 说明文件、Sheet、行号/业务键、字段、原值、原因；
- 能继续的字段继续；
- 不阻塞其他合同。

正常缺省不报异常：

- 当月订货文件未提供；
- 空白/VALUE；
- 当月订货合同无匹配；
- 无要货占位行及其空履约字段；
- 全部候选日期为空而自然无法计算到货日期。
