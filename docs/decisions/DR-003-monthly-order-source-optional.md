# DR-003 当月订货源文件可选

- 状态：`CONFIRMED`
- 日期：`2026-08-26`
- 关联：
  - `docs/requirements-baseline.md`
  - `docs/source-schema.md`
  - `docs/output-schema.md`

## 1. 决策

`当月订货`业务角色保留，但整个源 Excel 文件改为可选。

当前输入必选性：

```text
遗留量          必选
当月订货        可选
要货明细        必选
国家运输周期    必选
```

当月订货文件未提供属于正常运行模式，不记录异常，不阻止生成结果。

## 2. 文件未提供时的业务语义

```text
monthly_order source = absent
```

此时：

1. 不尝试打开当月订货文件；
2. 不执行该角色的 Sheet 定位和字段匹配；
3. 不产生缺文件、缺Sheet、缺字段异常；
4. `当月新订货`对所有正常业务行输出数值0；
5. BG 回退链跳过当月订货来源；
6. 合同全集不包含当月订货来源。

合同全集变为：

```text
遗留量合同号 ∪ 要货明细合同号
```

## 3. 文件提供时的业务语义

当月订货文件一旦由用户提供，就必须作为真实输入解析。

合同全集为：

```text
遗留量合同号 ∪ 当月订货合同号 ∪ 要货明细合同号
```

某合同在当月订货中无匹配时：

```text
当月新订货 = 0
```

不记录异常。

BG继续使用：

```text
遗留量 → 当月订货 → 要货明细
```

## 4. 未提供与不可识别必须区分

以下两种状态不能混为一谈：

### A. 用户没有选择当月订货文件

正常状态：

```text
source_status = ABSENT_OPTIONAL
```

不产生异常。

### B. 用户选择了当月订货文件，但无法识别业务数据

异常状态，例如：

```text
SHEET_ROLE_NOT_FOUND
AMBIGUOUS_SHEET_ROLE
MISSING_FIELD
AMBIGUOUS_FIELD
```

不能静默退化成“未提供文件”。

在错误证据已经记录的前提下，允许其余数据继续处理；本次当月订货数据不可用时，当月新订货按0降级。

## 5. Sheet 名不构成必选条件

当月订货文件存在时，业务数据 Sheet 可以叫：

```text
Sheet1
Sheet2
Sheet3
或其他名称
```

必须通过统一 `SheetLocator / SheetResolver` 按字段契约定位。

Sheet 名 canonical/alias只能作为优先提示，不能作为是否加载该数据源的必要条件。

该规则同样适用于其他三个源文件角色。

## 6. 实施影响

后续代码修复至少应包括：

- GUI：`当月订货 Excel`标记为“可选”；
- GUI：未选择当月订货时允许点击开始；
- Application：`monthly_order_path`允许为空/None；
- `RunRequest`/`SourceFiles`：表达可选源而不是伪造空路径；
- 配置：`monthly_order.optional=true`，其他三个角色保持false；
- 输入适配器：可选源未提供时直接跳过，不打开工作簿；
- 合同全集：仅合并实际可用源；
- BG回退：可选源不存在时直接跳过；
- 当月新订货：可选源不存在时统一为规范化数值0；
- SheetLocator：文件存在时按字段契约定位，不依赖固定Sheet名；
- 测试：覆盖有文件、无文件、自动Sheet名、无匹配合同、提供错误文件等情况。

## 7. 最小验收场景

必须至少通过：

1. 不选择当月订货文件，工具正常生成结果；
2. 不选择文件时，所有业务行当月新订货均为数值0；
3. 不选择文件时，BG按遗留量→要货明细回退；
4. 不选择文件时，合同全集=遗留量∪要货明细；
5. 选择有效当月订货文件时，合同全集恢复三表并集；
6. 选择有效文件但某合同无匹配时，该合同当月新订货=0；
7. 选择当月订货文件，业务数据位于`Sheet2`时可正确识别；
8. 选择错误/不可识别文件时产生明确异常，而不是显示为“未提供”；
9. 遗留量、要货明细、国家运输周期仍保持必选。
