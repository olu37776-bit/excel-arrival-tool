## 1. 金额空值与业务精度

最终基表中的：

- `遗留量`
- `当月新订货`

必须始终是可汇总的数值。

以下情况输出 `0`：

- 源单元格为空；
- 只有空白字符；
- `(空白)`占位；
- `#VALUE!`或等价VALUE标记；
- 当月订货按合同号无匹配；
- 其他非法非空金额在记录异常后使用0作为本次降级值。

### 1.1 浮点数不得直接判断是否为0

真实 Excel 金额单元格可能以浮点数读取，并出现科学计数法极小残留，例如：

```text
1E-12
-4.440892098500626E-16
0.0049
```

因此实现不得使用原始 `float == 0` 或 `float != 0` 作为收入分段判断。

统一规则：

1. 数值读取后使用十进制语义转换，例如 `Decimal(str(raw_value))`，不得直接使用 `Decimal(float_value)`；
2. 当前金额业务精度为小数点后2位；
3. 使用十进制四舍五入 `ROUND_HALF_UP` 量化到 `0.01`；
4. 量化后的金额等于 `0.00`，业务上视为0；
5. 量化后的金额不等于 `0.00`，业务上视为非0；
6. 原始浮点值虽非0、但量化后为0的精度残留，不记录异常；
7. 基表输出、透视汇总和收入分段判断都使用同一个量化后的金额值。

示例：

```text
1E-12      → 0.00 → 业务值为0
-0.0049    → 0.00 → 业务值为0
0.0049     → 0.00 → 业务值为0
0.005      → 0.01 → 业务值非0
-0.005     → -0.01 → 业务值非0
0.01       → 0.01 → 业务值非0
```

当前两位小数是正式业务精度。未来如业务调整金额精度，应修改统一金额规范化策略和对应测试，不得在收入分段规则中单独设置另一个阈值。

## 2. 空白与VALUE不进入异常清单

空单元格、纯空白、`(空白)`、`#VALUE!`和等价VALUE文本统一视为业务空值，不记录异常。

- 金额字段 → 0；
- 日期字段 → None；
- 普通文本和标识 → 空值。

## 3. 货未发完

```text
最晚RPD为空 → 空
最晚RPD有效、最晚ASD为空 → Y
最晚RPD和最晚ASD均有效，最晚RPD>最晚ASD → Y
最晚RPD和最晚ASD均有效，最晚RPD<=最晚ASD → N
```

正常空值导致无法判断时不记录异常。

## 4. 到货日期门控

### 按RPD

```text
货未发完 != Y：
  ATA → ATA
  否则 ASD+海运周期
  否则空

货未发完 = Y：
  不使用ATA/ASD
  最晚RPD+海运周期
  缺少必要值则空
```

### 按CPD

```text
货未发完 != Y：
  ATA → ATA
  否则 ASD+海运周期
  否则空

货未发完 = Y：
  不使用ATA/ASD
  CPD+海运周期
  缺少必要值则空
```

全部候选日期为空时，直接输出空到货日期，不记录异常。海运周期在已选路径中缺失时，仍记录运输周期异常。

## 5. 收入分段类别

```text
多次要货=Y → 需判断

否则ATA或ASD存在 → 发未收

否则RPD或CPD存在：
  遗留量业务值=0且当月新订货业务值=0 → 未录入订货
  任一金额业务值非0 → 订未发

否则 → 不要货
```

这里的“业务值为0/非0”必须使用第1.1节规定的两位小数十进制量化结果，禁止直接比较原始浮点数。

## 6. 异常边界

### 新增/保留异常

- 合同全集中的合同在要货明细完全找不到；
- 同一合同国家冲突；
- 同一要货明细行备货总控标识与发货总控标识均有效但不同；
- 字段缺失或歧义；
- 非空非法金额、日期、枚举或运输周期；
- 完全重复行被忽略。

### 不再作为异常

- 空白字符、空单元格、`(空白)`、VALUE占位；
- 同合同+履行供应中心下普通文本字段存在多个不同非空值；
- 当月订货按合同号无匹配；
- 所有候选日期为空而自然无法计算到货日期；
- 原始浮点数存在极小精度残留，但按两位小数业务精度量化后为0。

## 7. 实施影响

后续代码修复至少需要修改：

- 金额解析和默认值；
- 使用 `Decimal(str(value))` 的金额转换；
- 两位小数、`ROUND_HALF_UP` 的统一金额量化策略；
- 禁止用原始浮点数直接判断0/非0；
- 基表、变化清单和透视数据统一使用规范化金额；
- 全局空值标准化；
- 货未发完策略；
- RPD/CPD到货日期策略；
- 收入分段策略；
- 异常代码和异常生成位置；
- 合同未命中要货明细的错误消息；
- 要货明细同行总控标识一致性校验；
- 对应单元测试、集成测试和结果验收样例。

金额测试至少覆盖：

- `0`、`0.0`、`-0.0`；
- 科学计数法极小正负残留；
- `0.0049`、`0.005`、`-0.0049`、`-0.005`；
- 正常正数和负数；
- 空值、VALUE占位和非法文本。

本决策只定义业务边界，不指定具体类名或实现方式。
