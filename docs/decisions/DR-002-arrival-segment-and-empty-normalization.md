## 1. 决策背景

本次业务确认同时修改了：

- 遗留量、当月新订货的空值输出；
- 到货日期对“货未发完”的依赖；
- 收入分段类别；
- 空白字符和`#VALUE!`处理；
- 要货明细文本差异与总控标识异常；
- 合同进入全集但未出现在要货明细中的异常语义。

这些规则会直接影响领域计算和异常清单，不能只在Excel写出层做格式替换。

## 2. 金额空值统一为0

`遗留量`和`当月新订货`必须保持数值列。

以下情况统一输出数值`0`，不写异常：

- 空单元格；
- 空字符串或仅含空白字符；
- `(空白)`；
- `#VALUE!`；
- 合同在对应来源中没有匹配记录。

其他非法非空金额记录异常，但本次输出仍使用数值0，避免破坏后续透视和汇总列类型。

## 3. 空白字符与`#VALUE!`安静处理

以下值不进入异常清单：

- 半角/全角空格；
- 制表符、换行；
- 空字符串；
- `(空白)`；
- `#VALUE!`。

日期字段将其视为空日期；文本和标识将其视为空值；金额将其视为0。

除`#VALUE!`外的其他非空Excel错误仍按字段类型处理。

## 4. 到货日期先判断货未发完

### 4.1 逻辑冲突的消除

现有`货未发完=Y`定义为：

```text
最晚ASD、最晚RPD均有效
且 最晚RPD > 最晚ASD
```

因此字面上的“货未发完=Y且ASD为空”无法同时成立。

为使规则可实施，本次按业务目的确认：

- `货未发完=Y`表示已有ATA/ASD可能只代表部分批次，不能作为整单最终到货日期；
- 此时改用未完成批次的最晚计划日期加海运周期；
- `货未发完!=Y`时才允许使用ATA、ASD。

### 4.2 按RPD

```text
货未发完 = Y：
    最晚RPD + 海运周期

货未发完 != Y：
    ATA优先
    ATA无有效值时取ASD
    ATA、ASD均无有效值时留空
```

### 4.3 按CPD

```text
货未发完 = Y：
    CPD + 海运周期

货未发完 != Y：
    ATA优先
    ATA无有效值时取ASD
    ATA、ASD均无有效值时留空
```

补充：

- `货未发完=Y`时忽略已有ATA/ASD，不用其覆盖未完成批次；
- `货未发完!=Y`时不回退到RPD/CPD加周期；
- 所有相关日期无有效值时直接留空，不写缺日期异常；
- 分支需要海运周期但周期不可用时，到货日期留空，并保留运输周期异常。

## 5. 收入分段类别

```text
1. 多次要货 = Y
   → 需判断

2. 多次要货 != Y，ATA或ASD任一有效
   → 发未收

3. 多次要货 != Y，ATA/ASD均无有效值，RPD或CPD任一有效
   - 遗留量=0 且 当月新订货=0 → 未录入订货
   - 遗留量、当月新订货任一不为0 → 订未发

4. 多次要货 != Y，ATA/ASD/RPD/CPD均无有效值
   → 不要货
```

收入分段必须使用金额字段规范化后的数值结果。

## 6. 异常口径

### 6.1 合同未出现在要货明细

合同由三表并集进入全集，但要货明细中没有相同合同号时：

- 记录`CONTRACT_NOT_FOUND_IN_DEMAND_DETAIL`；
- 不生成正常业务行；
- 不描述为“已找到合同但缺少供应中心”。

### 6.2 要货组内文本差异

同一`合同号 + 履行供应中心`下普通文本字段存在多个不同非空值，不视为异常。需要单值时取第一条有效值。

### 6.3 同行总控标识不一致

同一条要货明细记录中：

```text
备货总控标识、发货总控标识均为有效非空Y/N
且值不同
→ CONTROL_FLAG_MISMATCH
```

空白字符、`(空白)`或`#VALUE!`不触发该异常。

## 7. 影响范围

后续代码修复必须同步更新：

- 源值规范化；
- 金额模型和Excel数值输出；
- 货未发完与到货日期策略；
- 收入分段策略；
- 异常代码与异常清单；
- RPD/CPD变化和供应差异清单中的金额字段；
- 单元测试、集成测试及真实结果验收。

GUI只负责收集文件和展示运行结果，不得在GUI中实现上述规则。
