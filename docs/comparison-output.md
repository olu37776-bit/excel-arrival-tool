## 1. 输出工作簿

一次运行生成一个结果工作簿，至少包含：

1. `基表`
2. `RPD跨月变化`
3. `CPD跨月变化`
4. `异常清单`

变化清单均为标准二维表，第一行为表头，开启筛选并冻结首行。

## 2. 比较键

```text
合同号 + 履行供应中心
```

内部实现使用：

```text
contract_no + supply_center
```

## 3. 比较来源

比较上一次成功运行基表与本次基表中的自动字段：

- `收入年月（按RPD）`
- `收入年月（按CPD）`

人工调整月份不替代自动收入年月参与变化比较。

首次运行无上期结果时，两张变化 Sheet 只输出表头。

## 6. 入表规则

### 两期都有年月

年月相同：不进入变化清单。

年月不同：进入变化清单。

```text
本期 > 上期 → 变化方向 = 延后
本期 < 上期 → 变化方向 = 提前
变化月数 = 两个月份之间的绝对月份差
```

例如：

```text
2026-09 → 2026-10：延后，1
2026-11 → 2026-09：提前，2
```

### 空值状态变化

以下也进入变化清单：

```text
上期空 → 本期有 → 变化方向 = 新增
上期有 → 本期空 → 变化方向 = 取消
```

此时 `变化月数` 留空，不虚构月份差。

两期都为空：不进入变化清单。

如果某期为空是因为数据异常导致无法计算，该记录仍可进入变化清单，同时对应原因必须出现在 `异常清单`。

## 7. 数据字段取值

变化清单中的合同号、遗留量、当月新订货、地区部、国家、客户群、履行供应中心默认取本期基表值。

如果本期业务行已经消失而只存在上期记录，则使用上期可用属性，并将变化方向视为取消/消失类状态；具体业务行消失的展示可在实现阶段通过统一比较器处理。

## 8. 历史基线

当前默认与“上一次成功运行”比较。

上一次结果由用户选择还是工具自动定位最近一次成功结果，属于交互实现选择，不改变本文件的业务比较规则。
